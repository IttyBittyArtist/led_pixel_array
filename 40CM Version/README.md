# 3D LED Pixel Array - 40CM

We have created a tool that can help you generate a pixel array cut template: 

https://www.electronicmayhem.com/pixel-array-frame-assembly/

You can enter the thickness of your boards (up to 7mm thick) and view the diagram/generate parts for a module that is either glued together or bolted together.

Please consider kicking us a few bucks if you use this. It really helps us cover the cost of materials and tools to develop future work.

Templates will be added when we get them up-to-date using a POPs workflow.
